### Plugins

Use these plugins to automate subscription actions, customize user profiles and content, and connect Membership Pro to other extensions and services.

- [System - Membership Pro](/plugins/system-membership-pro). Handles system-level Membership Pro tasks.
- [Update Subscribers Status](/plugins/update-subscribers-status). Updates expired subscription records.
- [System - Registration Redirect](/plugins/registration-redirect-plugin). Redirects account registration to Membership Pro.
- [Limit Subscriptions](/plugins/limit-subscriptions-plugin). Limits the number of subscriptions a plan accepts.
- [Membership Pro - Auto Subscribe](/plugins/auto-subscribe). Adds subscribers to other plans automatically.
- [Membership Pro - Subscription Control](/plugins/subscription-control). Controls when subscriptions to other plans start or expire.
- [Plan Subscribing Restriction](/plugins/plan-subscribing-restriction). Restricts sign-ups based on active subscriptions to other plans.
- [Membership Pro - PHP Script](/plugins/script-plugin). Runs PHP code on subscription events.
- [Fields Assignment](/plugins/fields-assignment). Assigns custom fields from a plan's settings.
- [GeoIP](/plugins/geoip). Detects a subscriber's country from their IP address.
- [Delete User Account](/plugins/delete-user-account). Deletes a Joomla account when its subscription records are removed.
- [Membership Pro - User Files](/plugins/user-files). Makes files available to individual users from their profiles.
- [Membership Pro - User Coupons](/plugins/membership-pro-user-coupons). Shows assigned coupons in a user's profile.
- [EB Registration History](/plugins/eb-registration-history). Shows Events Booking registrations in the user profile.
- [Helpdesk Pro Tickets History](/plugins/helpdesk-pro-tickets-history). Shows Helpdesk Pro tickets in the user profile.
- [Multi-factor Authentication](/plugins/multi-factor-authentication). Lets subscribers configure authentication methods in their profile.
- [Membership Pro - K2 Groups](/plugins/k2-groups). Assigns subscribers to K2 groups.
- [Virtuemart Shopper Groups](/plugins/vm-shopper-groups). Assigns subscribers to Virtuemart shopper groups.
- [Content - Membership Plans](/plugins/content-membership-plans). Displays selected plans in Joomla content.
- [Content - Membership Tags](/plugins/content-membership-tags). Displays subscriber information in Joomla content.
- [Content - Subscription Form](/plugins/content-subscription-form). Embeds a plan's subscription form in Joomla content.
- [User - Membership Pro](/plugins/user-membership). Subscribes users when they register for a Joomla account.
- [Smart Search](/plugins/smart-search). Makes plans searchable through Joomla Smart Search.
- [Webhook](/plugins/webhook). Sends subscription data to an external URL.
- [Actions Log](/plugins/actions-log). Records Membership Pro actions in Joomla's action log.
- [MPDF](/plugins/mpdf). Provides an alternative PDF generator for invoices and membership cards.
- [Offline Recurring Invoice](/plugins/offline-recurring-invoice). Legacy plugin for offline recurring invoices.
- [Membership Pro Cleaner](/plugins/cleaner-plugin). Legacy plugin for removing unpaid online subscriptions.
- [Membership Pro Clean Email Logs](/plugins/clean-email-logs). Legacy plugin for cleaning email logs.
- [Incomplete Payment Notification](/plugins/incomplete-payment-notification). Legacy plugin for reporting incomplete payments.
