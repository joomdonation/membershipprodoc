title: 'Content - Membership Tags'
published: true
---

This plugin provides tags for displaying information about the logged-in subscriber in a Joomla article or on another page that supports Joomla content plugins, such as a K2 item.

If you want to use this feature, please follow the instructions below:

1. Go to **System -> Plugins**, find and enable the plugin **Content - Membership Tags**.
2. Now, edit the article you want to show subscriber information, use the following tags to display the information you want from subscriber:

## User Information

- [USERNAME]
- [NAME]
- [USER_GROUPS]

## Subscription Information

- Use syntax [NAME_OF_CUSTOM_FIELD_IN_UPPERCASE] to display value of any custom field you want. For example [FIRST_NAME], [LAST_NAME], [ORGANIZATION], [EMAIL]
- [MEMBER_ID]
- [ACTIVE_PLANS]
- [EXPIRED_PLANS]
