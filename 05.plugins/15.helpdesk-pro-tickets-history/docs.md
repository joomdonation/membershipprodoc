If you use Membership Pro and **[Helpdesk Pro](https://joomdonation.com/joomla-extensions/helpdesk-pro-joomla-helpdesk.html)** on the same site, this plugin displays a subscriber's support ticket history in their Membership Pro user profile.

To use this plugin, go to **System -> Plugins**, find and publish **Membership Pro - Helpdesk Pro Tickets History** plugin. Now, when subscriber access to his Membership Pro user profile, he will see his support tickets history on a new tab on profile
