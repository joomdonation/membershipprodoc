This plugin allows you to display Helpdesk Pro support tickets history of a subscriber in his Membership Pro user profile. This is useful in case you are using Membership Pro and our **[Helpdesk Pro](https://joomdonation.com/joomla-extensions/helpdesk-pro-joomla-helpdesk.html)** extension together on the same site

To use this plugin, go to **System -> Plugins**, find and publish **Membership Pro - Helpdesk Pro Tickets History** plugin. Now, when subscriber access to his Membership Pro user profile, he will see his support tickets history on a new tab on profile
