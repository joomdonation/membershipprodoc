This plugin can add subscribers to selected Virtuemart Shopper Groups when they sign up for a plan and remove them when their subscription expires.

To use this plugin, go to **System -> Plugins**, find and publish **Membership Pro - Virtuemart Shopper Groups** plugin. Then edit the subscription plan, look at **Virtuemart Shopper Groups Settings** tab, make necessary settings to get it works as you want.
