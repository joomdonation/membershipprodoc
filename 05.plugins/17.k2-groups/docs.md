Like the Joomla Groups plugin, this plugin assigns subscribers to selected **K2 Groups** when their subscription becomes active and removes them when it expires.

Use it to grant subscribers specific permissions in K2.

Go to **System** -> **Plugins** and enable **Membership Pro - K2 Groups**. Then edit the plan and configure the **K2 Groups Settings** tab.
