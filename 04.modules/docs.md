title: Modules
---

Membership Pro provides modules for displaying subscription plans and membership status in a module position in your site template. The sections below explain how to use each module.

## Membership Plans
Create an instance of **Membership Plans** and publish it in a module position in your site template to display a list of plans. The module has the following settings.
* **Layout**: Choose **Default Layout**, **Columns Layout**, or **Pricing Table Layout**.
* **Plan Ids**: Enter the IDs of the plans to display, separated by commas. Leave this field blank to display all published plans.
* **Recommended Plan ID**: Enter the ID of the plan to feature as recommended. This setting applies only to the pricing table layout.
* **Menu Item ID**: Enter the ID of the fallback menu item to use for SEF links to plans that have no menu item. If you leave this field blank, the module attempts to select a suitable menu item automatically.

## Membership Status
This module shows the logged-in user their plan, expiration date, and the number of days remaining. Create an instance of **Membership Status** and publish it in a module position in your site template.
