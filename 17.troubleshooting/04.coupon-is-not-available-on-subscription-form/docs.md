---
title: 'Coupon is not available on subscription form'
visible: true
---

After creating a coupon code in Membership Pro, you may find that the subscription form has no field for entering it.

1. You haven't enabled coupon feature yet. Go to Membership Pro -> Configuration, check and make sure **Enable Coupon** parameter set to Yes
2. You will also check and make sure there is at least one valid coupon code is available for the plan you signed up for:
- Check the Plan setting, make sure it set to All Plans or have the plan you are signing up for selected
- Make check and make sure current date is between **Valid From Date** and **Valid To Date** setting of the coupon. Better, leave the two settings empty
