# Advanced Features

Set up member downloads, release articles over time, offer group memberships, or embed Membership Pro views in module positions.

- [Downloads Manager Plugin](/advanced-features/downloads-manager-plugin). Give active subscribers access to plan-specific files.
- [Schedule (Drip-Feed) Content plugin](/advanced-features/schedule-drip-feed-content-plugin). Release Joomla articles based on how long a user has subscribed.
- [Group Membership](/advanced-features/group-membership). Let a group administrator manage group members under a subscription plan.
- [Display View In Module](/advanced-features/display-view-in-module). Show a Membership Pro view in a module position.
