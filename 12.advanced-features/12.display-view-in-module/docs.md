---
title: 'Display View In Module'
---

This is a special feature allow you to display a view in the extension (Categories, Plans List, Subscription Form, User Profile, Members List, Subscription History, Renew Membership. Upgrade Membership) inside a module on your site. (Normally, you will have to create a menu item to display a view in the extension)

1. Create a hidden menu item link to the view which you want to display, configure the necessary parameters in the menu item parameters.
2. Go to Extensions -> Modules, create a new instance of **Membership Pro View** module, assign it to the position you want in the template
3. Click on the module to edit, there is a parameter called **Menu Item**, choose the hidden menu item which you created above.
