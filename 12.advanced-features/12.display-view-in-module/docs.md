---
title: 'Display View In Module'
---

Use this feature to display a Membership Pro view in a module. Supported views include Categories, Plans List, Subscription Form, User Profile, Members List, Subscription History, Renew Membership, and Upgrade Membership. Membership Pro normally displays a view through a menu item.

1. Create a hidden menu item for the view you want to display and configure its parameters.
2. Go to Extensions -> Modules, create an instance of **Membership Pro View**, and assign it to a position in your template.
3. Edit the module and select the hidden menu item in **Menu Item**.
