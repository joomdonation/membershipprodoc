---
title: 'Input Mask'
published: true
---

Membership Pro is now integrated with Input Mask library from [imask.js.org](https://imask.js.org/) to allow you to define input mask for each custom field to force users to enter data in the format you want. You can use [Regex](https://imask.js.org/guide.html#masked-base) or [Pattern](https://imask.js.org/guide.html#masked-pattern)  to define input mask for your custom fields.
