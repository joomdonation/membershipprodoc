published: true
---

Membership Pro uses the input mask library from [imask.js.org](https://imask.js.org/) to require users to enter data in a specific format. Use [Regex](https://imask.js.org/guide.html#masked-base) or [Pattern](https://imask.js.org/guide.html#masked-pattern) to define an input mask for each custom field.
