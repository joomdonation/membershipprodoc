The **Task - Membership Pro** plugin provides the scheduled tasks listed below.

- [**Membership Pro - Offline Payment Reminder**](/scheduled-tasks/offline-payment-reminder)
- [**Membership Pro - Offline Recurring Invoice**](/scheduled-tasks/offline-payment-reminder)
- [**Membership Pro - Update Subscriptions Status**](/scheduled-tasks/update-subscriptions-status)
- [**Membership Pro - Trigger Active Event**](/scheduled-tasks/trigger-active-event)
- [**Membership Pro - Calculate Subscribers Coordinates**](/scheduled-tasks/calculate-subscribers-coordinates)
- [**Membership Pro - Delete Incomplete Payment Subscriptions**](/scheduled-tasks/delete-incomplete-payment-subscriptions)
- [**Membership Pro - Incomplete Payment Subscriptions Notification**](/scheduled-tasks/incomplete-payment-subscriptions-notification)
- [**Membership Pro - Clean Emails Log**](/scheduled-tasks/clean-emails-log)
- [**Membership Pro - Delete Old Subscriptions**](/scheduled-tasks/delete-old-subscriptions)
- [**Membership Pro - Delete Old Invoices**](/scheduled-tasks/delete-old-invoices)
- [**Membership Pro - Delete PDF Members Card**](/scheduled-tasks/delete-old-member-cards)

Go to **System -> Plugins** and enable **Task - Membership Pro**. Create a scheduled task of the type you need, then let Joomla run it automatically.
